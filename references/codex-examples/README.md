# Codex visual references

These sheets are the composition target for the illuminated Codex page. They are other characters. The page template must not copy their names, stats, items, or lore. Live `sheetData` fills the zones. An empty field drops its panel. A missing portrait, crest, or item vignette is an engraved sigil.

| File | What to match |
|---|---|
| `01-ossian-kaelith-varel.jpg` | Light parchment. Top stat strip, left lore, right equipment callouts with item vignettes, bottom stat block. |
| `02-ebon-vanguard-mage.jpg` | Closest target. Aged parchment, full-bleed double frame, serif title, dominant portrait, annotated side callouts, bottom detail panels, footer inscription. |
| `03-iron-ronin.jpg` | Dark dossier. Spec callouts: icon, caps label, short detail. Same anatomy on a non-parchment ground. |
| `04-dark-knight-plate.jpg` | One dominant figure, equipment and stats orbiting it. |

Place the four JPEG files in this directory. They are visual reference only and are not imported by the renderer.
